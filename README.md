# wa-digest

Сервис для VDS, который читает ваши чаты WhatsApp, делает из них выжимку языковой моделью и присылает её в Telegram.

Бот в групповой чат **не добавляется**. Приложение подключается к WhatsApp как ещё одно связанное устройство — так же, как WhatsApp Web или Desktop, — и читает переписку от вашего имени.

- **Только чтение.** Приложение физически не умеет отправлять сообщения в WhatsApp: в коде нет такого пути.
- **Не мешает вам.** Прочтения не отправляются, статус «онлайн» не выставляется. Чаты остаются непрочитанными, пуши на телефон продолжают приходить.
- **Работает без телефона.** Телефон нужен один раз, чтобы отсканировать QR. Дальше сессия живёт на сервере, даже если телефон выключен.

## Как это работает

```
WhatsApp ──(WebSocket, Baileys)──▶ приём сообщений ──▶ SQLite
                                                        │
                             cron / команда в Telegram ─┤
                                                        ▼
                                            summary через LLM
                                                        │
                                                        ▼
                                          ваш личный чат в Telegram
```

Всё живёт в одном процессе Node.js: соединение с WhatsApp, Telegram-бот, планировщик и веб-панель.

## Быстрый старт в Docker

```bash
git clone https://github.com/Fram90/wa-summary-proxy.git wa-digest
cd wa-digest
cp .env.example .env
nano .env            # минимум: OPENAI_API_KEY, TELEGRAM_BOT_TOKEN, DASHBOARD_TOKEN

mkdir -p data && sudo chown -R 1000:1000 data   # в контейнере процесс работает под uid 1000
docker compose up -d --build
docker compose logs -f
```

Дальше:

1. Откройте панель. По умолчанию она слушает только localhost, поэтому с ноутбука сделайте туннель:
   ```bash
   ssh -L 43117:127.0.0.1:43117 user@ваш-vds
   ```
   и зайдите на http://127.0.0.1:43117
2. На вкладке «Подключение» отсканируйте QR: на телефоне Настройки → Связанные устройства → Привязка устройства. QR также печатается в `docker compose logs`, можно сканировать прямо из терминала.
3. Дождитесь синхронизации истории — WhatsApp пришлёт её сам, обычно за последние месяцы.
4. На вкладке «Чаты» отметьте те, за которыми стоит следить.
5. Напишите своему боту в Telegram `/start` — он запомнит ваш chat id и станет присылать дайджесты.

### Запуск без Docker

```bash
npm ci && npm --prefix web ci
npm run build
cp .env.example .env && nano .env
node dist/index.js
```

Для автозапуска есть готовый юнит: [deploy/wa-digest.service](deploy/wa-digest.service).

### Разработка

```bash
npm ci && npm --prefix web ci
cp .env.example .env
echo 'DEMO_MODE=true' >> .env    # WhatsApp не подключается, панель работает на примерах
npm run dev                      # сервер на :43117, Vite на :43118 с проксированием /api
```

## Настройки

Всё задаётся переменными окружения, полный список с комментариями — в [.env.example](.env.example). Самое важное:

| Переменная | Зачем |
| --- | --- |
| `OPENAI_API_KEY`, `OPENAI_BASE_URL`, `LLM_MODEL` | доступ к модели; подойдёт любой OpenAI-совместимый провайдер |
| `TELEGRAM_BOT_TOKEN` | токен от [@BotFather](https://t.me/BotFather) |
| `TELEGRAM_CHAT_ID` | куда слать дайджесты; пусто — личка того, кто первым напишет /start. Группа: добавьте бота и напишите там `/here` |
| `DASHBOARD_TOKEN` | пароль к панели; обязателен, если она видна из интернета |
| `DIGEST_CRON`, `DIGEST_TZ`, `DIGEST_WINDOW_HOURS` | когда присылать дайджест и за какой период |
| `RETENTION_DAYS` | через сколько дней удалять сохранённые сообщения |

Расписание, окно, модель и получателя можно менять на вкладке «Настройки» без перезапуска.

### Локальная модель вместо облачной

Если переписку не хочется отдавать наружу, поднимите Ollama на том же сервере и укажите её как провайдера:

```env
OPENAI_BASE_URL=http://host.docker.internal:11434/v1
OPENAI_API_KEY=ollama
LLM_MODEL=qwen2.5:14b-instruct
```

## Команды Telegram-бота

| Команда | Что делает |
| --- | --- |
| `/summary [часы]` | выжимка по отслеживаемым чатам за N часов |
| `/chats` | включить или выключить слежение за чатом |
| `/status` | состояние сессии WhatsApp и статистика |
| `/window N` | окно планового дайджеста |
| `/settings` | текущие настройки |

Бот приватный: команды слушает только владелец. Дайджесты по умолчанию приходят ему в личку. Чтобы публиковать их в группу, добавьте бота в неё и отправьте там `/here` со своего аккаунта. `/dm` возвращает доставку в личные сообщения. Остальные участники группы ботом управлять не могут.

## Свой промпт у чата и лишние вызовы модели

На вкладке «Чаты» у каждого чата есть свой текст для модели. Он добавляется только к выжимке этого чата. Пример для чата с уроками: «Если есть домашняя работа, вынеси её отдельным блоком: что задали и срок. Если домашки не было — так и напиши».

Фото модель не распознаёт. Если у чата задан свой промпт, новые фото из него пересылаются в Telegram отдельными сообщениями, как есть, вместе с подписью и автором. Без своего промпта фото остаются в тексте пометкой `[фото]`.

Плановый и ручной дайджест вызывают модель только если с прошлого дайджеста этого чата появились новые сообщения. Повторный запуск по тем же сообщениям модель не трогает. Кнопка «Применить к текущему окну» в окне промпта — исключение: она прогоняет уже виденное окно ещё раз.

## Что стоит знать заранее

- **История ограничена.** Связанное устройство получает историю только при первичной привязке. Дальше можно догружать порциями по 50 сообщений (кнопка в списке чатов), но выгрузить переписку за все годы нельзя — это ограничение протокола.
- **Риск блокировки.** [Baileys](https://github.com/WhiskeySockets/Baileys) — неофициальный клиент, формально это нарушение условий WhatsApp, и аккаунт теоретически могут заблокировать. Приложение ведёт себя тихо: только читает, не рассылает, не переподключается без нужды.
- **Ключи сессии лежат на сервере.** Каталог `data/` — это доступ к вашей переписке. Не выставляйте панель в интернет без `DASHBOARD_TOKEN`, лучше держите её за SSH-туннелем.
- **Чужие сообщения уходят в модель.** Остальные участники чата об этом не знают. Для чувствительных чатов используйте локальную модель.
- **Версия Baileys зафиксирована** на `6.7.24`. В ветке `7.0.0-rc` открыт баг [#2737](https://github.com/WhiskeySockets/baileys/issues/2737): QR-привязка не завершается, а `requestPairingCode()` возвращает недействительный код. Обновляйтесь только после его закрытия.

## Нет QR, статус «переподключается», ошибка Connection Terminated

Это не сеть VDS и не «WhatsApp не видит сервер». Сокет до WhatsApp доходит, сервер принимает TCP и сразу закрывает рукопожатие кодом **428**, ещё до выдачи QR.

С июня 2026 WhatsApp отклоняет клиентов, которые представляются как Desktop (`Browsers.macOS('Desktop')` → `webSubPlatform: DARWIN/WIN32`). Приложение теперь подключается как Chrome. После обновления:

```bash
git pull
docker compose up -d --build
```

Затем в панели нажмите **«Привязать заново»** — это сотрёт полубитую сессию после 15 неудачных рукопожатий — и подождите QR.

Если 428 останется и после этого:

1. `docker compose logs --tail=80` — в логе будет человеческое описание и код закрытия.
2. Код **403** — WhatsApp не любит IP датацентра. Попробуйте другой VPS или исходящий прокси.
3. Код **408** сразу после сканирования QR — устарела версия WhatsApp Web; приложение берёт её с `web.whatsapp.com`, перезапуск обычно помогает.
4. Убедитесь, что контейнер может ходить в интернет: `docker compose exec wa-digest node -e "fetch('https://web.whatsapp.com').then(r=>console.log(r.status))"`

## Стоимость

Чат на 1000 сообщений в сутки — это примерно 60–100 тысяч токенов на один дайджест. Расход по каждому дайджесту виден в панели.

## Структура

```
src/
  config.ts           переменные окружения через zod
  settings.ts         настройки, меняемые на ходу
  db/                 SQLite: схема и запросы
  whatsapp/
    client.ts         соединение с WhatsApp на Baileys
    message.ts        извлечение текста из всех типов сообщений
    demo.ts           демо-режим с посеянными данными
  summarize/          промпты, нарезка на части, сборка дайджеста
  telegram/           бот и форматирование под Telegram
  scheduler.ts        cron и удаление старых сообщений
  http/server.ts      API панели
web/                  панель: React, Tailwind, shadcn/ui
```
